## 未リリース

- 田園丘陵に樹木と低木を増やした(糸杉の並木、道沿いの茂み、窪地の雑木林、一本立ちの木、畑の外の林)。田園丘陵を既定のマップにした。
- 舞台を中部イタリアの田園に決め、一年の段階を「収穫 → 梱包 → 耕起 → 整地 → 播種 → 生育(冬)→ 追肥(飛ばせる)→ 生育(春〜初夏)」にした。
- 一年の進め方を決めた(段階ごとに全部の畑の作業を済ませて次へ進む。段階の中では畑を選べる)。
- 芝刈りシミュレーターから小麦畑の一年を描くアプリ(wheatfield)へ方向を変えた。リポジトリを移し、アプリ名を変更。目的・計画・構想の文書を書き直した。

- 「田園丘陵」マップを追加。長い波長の丘、農道で分かれた八つの草地、土地ごとの草色、道沿いの針葉樹を配置。
- 農道は距離・縦断勾配・横断勾配を評価して生成する。農道と畦は自動草刈りの対象から外し、樹木の幹の周囲は通行範囲からも外す。
- このマップは土地境界を固定し、「区画の広さ」の設定を表示しない。開始時の俯瞰を土地全体を見やすい位置へ変更。
- ビルドと全72件のテスト、Electron の俯瞰表示と短時間の自動走行を確認。
