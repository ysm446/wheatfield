# wheat-concept — 小麦畑の一年 構想メモ

作成日時: 2026-11-15 21:09
更新日時: 2026-11-15 21:13

目的と完成形は [goals.md](../plan/goals.md)、実装の段取りは [plan.md](../plan/plan.md) を参照。芝刈りのころの構想は [concept.md](concept.md)。

## 1. どんなものを作るか

田園丘陵の畑で、秋まき小麦の一年を描く。機械が畑を往復するたびに畑の様子が変わり、季節が進むと色が変わる。それを見下ろしのミニチュア風の絵で眺める。

## 2. 一年の流れ(秋まき小麦)

| 時期 | 作業・様子 | 畑に残るもの | 機械 |
| --- | --- | --- | --- |
| 9〜10 月 | 耕起 | 反転した土の畝。耕す前の刈り株との境目 | トラクター + プラウ |
| 10 月 | 整地 | 細かくならされた土。作業の向きの細い筋 | トラクター + パワーハロー |
| 10〜11 月 | 播種・鎮圧 | 条(すじ)。作業道(トラムライン)の空き | トラクター + ドリル、鎮圧ローラー |
| 11〜3 月 | 出芽・越冬 | 条に沿った緑の点線から一面の緑へ。雪をかぶることもある | なし |
| 4〜5 月 | 茎立ち・出穂 | 背が伸び、穂が出る。風で波打つ | なし |
| 6〜7 月 | 黄熟(麦秋) | 黄金色。場所によって熟し方にむら。倒伏した所 | なし |
| 7 月 | 収穫 | 刈り株、刈り跡の縞、後ろに麦わらの列(ウインドロー) | コンバイン |
| 7〜8 月 | 梱包 | 列が消え、ロールベールが点々と並ぶ | トラクター + ロールベーラー |
| 8〜9 月 | 刈り株の畑 | ベールの回収後、刈り株のまま次の耕起を待つ | (ベールの回収は後回し) |

麦踏み、追肥、防除、ベールの回収は後の段階で検討する。

## 3. 作業の進め方(段階)

一年を段階に分け、全部の畑でその段階の作業が終わったら次の段階へ進む。段階の中では、どの畑から作業するかを選べる。段階ごとに使う機械が変わる。

| 段階 | 使う機械 | 作業の有無 |
| --- | --- | --- |
| 1. 耕起 | トラクター + プラウ | 畑ごとに作業する |
| 2. 整地 | トラクター + パワーハロー | 畑ごとに作業する |
| 3. 播種 | トラクター + ドリル(鎮圧輪付き) | 畑ごとに作業する |
| 4. 生育 | なし | 作業はない。冬から初夏まで早送りで眺める |
| 5. 収穫 | コンバイン | 畑ごとに作業する |
| 6. 梱包 | トラクター + ロールベーラー | 畑ごとに作業する |

梱包が終わると耕起に戻り、次の年になる。

- **段階の切り替え**: 全部の畑の作業が終わると「次の段階へ」を選べるようになる。選ぶと、次の段階の時期まで暦を早送りし、機械が入れ替わる(機械は農道の決まった場所から出てくる)。生育の段階は、作業がないので収穫の時期まで早送りする。
- **段階の中**: 畑は「まだ・作業中・済み」のどれか。管制の視点で機械を選び、畑を右クリックして向かわせる(芝刈りのころの区画への指示と同じ操作)。自動モードでは、まだの畑のうち近いものから順に回る。
- **作業済みの判定**: 畑の中で機械が入れる範囲のうち、作業した割合が決まった値(案: 95%)を超えたら済みにする。刈り残しのような小さな残りで先へ進めなくなるのを防ぐ。
- **段階の途中の景色**: 耕した畑と耕していない畑が並ぶような、段階の途中のまだらな景色も見どころとして扱う。
- **鎮圧**: 段階を増やしすぎないよう、ドリルに付いた鎮圧輪で済ませる。独立したローラーの作業(麦踏みなど)は後で検討する。
- **暦**: 作業中は暦が作業の速さに合わせて進む。段階の切り替えでは次の時期の初めまで飛ばす。作業が遅れても段階が先に進むことはない(段階が暦より優先)。

## 4. 畑の状態マップ

芝状態マップ(丈、寝ている向き、鮮度)を、畑の状態を持つマップに作り替える。地面に対応する 2D テクスチャで持ち、機械の作業幅の形を描き込んで更新する点は変えない。

持ちたい値の案:

- 土の状態: 耕していない(刈り株)、耕した、整地した、まいた。
- 作業の向き: 最後に通った機械の進行方向(筋や縞の向き)。
- 生育: まいた時刻。生育段階は暦と場所ごとのむらから求める。
- 作物の丈と倒れ方(風、倒伏、タイヤ)。
- 刈り株の丈。
- 麦わらの量(列の濃さ)。
- タイヤの跡、作業道。

ロールベールはマップではなく物として置く。

## 5. 見た目

- 遠くの麦は地面シェーダーで描く(色、穂波の明暗、作業の縞)。近くは一本ずつインスタンシングで茎と穂を描き、風でなびかせる。中間は高さのある面で厚みを出す方法を検討する(視差を出すシェーダーなど)。
- 土は耕した直後の湿った濃い色から、乾いて明るくなる。畝の凹凸は法線と影で出す。
- 季節の色: 秋の土色 → 冬の緑の点線 → 春の濃い緑 → 初夏の黄金色 → 刈り株の淡い黄色。
- 麦わらの列とロールベールは、見下ろしで形が分かる大きさと陰影を付ける。

## 6. 機械

すべて Blender のスクリプトで作る。芝刈り機と同じく、寸法(車輪、作業幅、部品の位置)は機種の定義ファイル(JSON)に書き、アプリとスクリプトの両方がそれを読む。動く部品は名前で探して動かす。

| 機械 | 作業幅の目安 | 動く部品 |
| --- | --- | --- |
| トラクター | (牽引のみ) | 車輪、前輪の操舵 |
| プラウ | 1.5〜2 m(3〜4 連) | 上げ下げ |
| パワーハロー | 3 m | 上げ下げ、回転する爪 |
| ドリル | 3 m | 上げ下げ |
| 鎮圧ローラー | 3〜6 m | ローラーの回転 |
| コンバイン | 刈り幅 5〜6 m | 車輪、後輪の操舵、リール、刈り幅の上げ下げ、排わらの出口 |
| ロールベーラー | 拾い上げ 2 m | 拾い上げ、ベールを出す後ろの扉 |
| ロールベール | 直径 1.2〜1.5 m | なし |

トラクターと作業機は連結して動く(作業機はトラクターの後ろを引かれてついてくる)。

## 7. 経路

- 区分けと往復の経路計画、Pure Pursuit での追従は芝刈りのころのものを使う。
- 作業ごとに経路の作り方を変える。
  - 耕起: 畝を寄せ合う・離す向きをそろえる「ランド」の割り付け(プラウの耕し方の型)。
  - 播種: 作業道(トラムライン)の間隔に合わせた往復。
  - 収穫: 外周を数周刈ってから内側を往復。
  - 梱包: 麦わらの列をたどる。
- 区分けは「機械で入れる畑」と「入れない所」(急な斜面、農道、畦)を分ける用途に変える。

## 8. 時間

- 暦(日付)を持ち、タイムラプスで日が進む。作業の時期は暦で決める。
- 太陽の通り道は日付でも変える(冬は低く、夏は高い)。
- 早送りは、作業を見る速さ(数倍〜数十倍)と、季節を見る速さ(1 秒で数日)の二段にする。

## 9. 未決事項

- 作業済みと判定する割合(案: 95%)。
- 段階の中で、同じ段階の機械を何台使えるか(1 台か、複数台を同時に動かすか)。
- 雪を入れるか。
- 畑の数と形は田園丘陵の八つの土地を使うか。
