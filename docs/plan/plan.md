# plan — 実装方針と優先順位

作成日時: 2026-11-11 04:54
更新日時: 2026-11-15 21:19

目的は [goals.md](goals.md)、構想の詳細は [docs/reference/wheat-concept.md](../reference/wheat-concept.md) を参照。

2026-11-15 に芝刈りシミュレーターから小麦畑のアプリへ方向を変えた。芝刈りのころのマイルストーン(M0〜M8)は末尾の「旧マイルストーン」に残す。新しいマイルストーンは W0 から数える。

## 技術構成

- Electron + Three.js(WebGL2)+ TypeScript。ビルドは Vite(electron-vite)。
- テストは Vitest。区分け、経路計画、被覆計算、生育の計算は描画と切り離してテストする。
- 3D アセットは Blender で作り、glTF(.glb)で読み込む。機械のモデルは Blender のスクリプト(`tools/blender/`)で生成し、寸法は機種の定義ファイル(JSON)と共有する。
- Python は使わない見込み。補助スクリプトなどで使う場合は、リポジトリ直下の venv(`.venv`)で実行する。Blender 同梱の Python で動かすスクリプトは対象外。

## 実装方針

- 芝刈りのころに作った土台は使い続ける: 物理カメラ(自動露出、被写界深度、ミニチュア倍率、ティルト)、HDR 描画、大気と空、雲の影、地形、田園丘陵の農道と土地、樹木、区分け、往復の経路計画、Pure Pursuit の追従、タイムラプス、管制の視点、録画、音楽、UI。
- 芝生に固有の部分(芝の葉、芝の色と縞、刈りカス、芝刈り機のモデルと定義)は、小麦の部品ができた段階で順に外す。外す前に置き換え先を用意し、アプリが動かない期間を作らない。
- 芝状態マップは畑の状態マップに作り替える(土の状態、作業の向き、まいた時刻、作物の丈と倒れ方、刈り株、麦わらの量)。GPU 上で作業幅の形を描き込む仕組みは変えない。
- 遠くの麦は地面シェーダー、近くはインスタンシングの茎と穂で描く。両者の色は同じ式でつなぐ(芝のときの `GRASS_GLSL` と同じ考え方)。
- 機械は「機種の定義ファイル → Blender スクリプトでモデル生成 → アプリが定義を読んで作業幅や部品の動きを決める」という芝刈り機の流れに揃える。トラクターと作業機は連結して動かす。
- 舞台は中部イタリアの田園。暦と太陽の通り道もそれに合わせる。
- 一年は段階(収穫 → 梱包 → 耕起 → 整地 → 播種 → 生育(冬)→ 追肥 → 生育(春〜初夏))で進める。全部の畑で段階の作業が済んだら次へ進み、機械が入れ替わる。段階の中では畑を選んで作業する。追肥は飛ばせる。詳しくは [wheat-concept.md の「作業の進め方」](../reference/wheat-concept.md#3-作業の進め方段階)。
- 作業ごとに経路の作り方を変える(収穫は外周から、耕起はランドの割り付け、梱包は麦わらの列をたどる)。経路の生成と追従は分けたままにする。
- 時間は暦(日付)で持つ。生育は暦と場所ごとのむらから求め、シミュレーションは固定時間刻みで進める。
- 見た目の核になる「黄金色の麦畑をコンバインで刈る」を最初に作り、成立を確かめてから一年の他の作業へ広げる。

## マイルストーン

W0 を進めている。現在の状況は [progress.md](progress.md) を参照。

| 段階 | 内容 | 完了の目安 |
| --- | --- | --- |
| W0 移行 | リポジトリを wheatfield に移す。目的と計画を小麦畑向けに書き直す。アプリ名を変える | 新しいリポジトリに履歴ごと移り、文書が新しい方針になっている |
| W1 麦畑の描画 | 畑の状態マップ、地面シェーダーの麦と土、近景の茎と穂、風でなびく穂波。芝の葉と芝の色を外す | 田園丘陵の畑が黄金色の麦畑に見え、生育段階を変えると緑から黄金色まで変わる |
| W2 コンバインで収穫 | Blender 製のコンバイン(定義ファイル + スクリプト)、刈り取りで刈り株と麦わらの列が残る、収穫の経路(外周 → 往復)。芝刈り機を外す | 自動運転で一枚の畑を刈り終え、刈り跡と麦わらの列が見える |
| W3 麦わらの梱包と段階の仕組み | Blender 製のトラクターとロールベーラー、連結した走行、列をたどる経路、ロールベールを置く。畑ごとの「まだ・作業中・済み」と、全部済んだら次の段階へ進み機械が入れ替わる仕組み | 全部の畑を収穫すると梱包の段階に進み、麦わらの列が消えてロールベールが並ぶ |
| W4 耕起と整地 | Blender 製のプラウとパワーハロー、土の状態と畝の見た目、ランドの割り付けの経路 | 刈り株の畑を耕して整地すると、作業の跡が見分けられる |
| W5 播種と追肥 | Blender 製のドリル(鎮圧輪付き)と肥料散布機、条と作業道、出芽、作業道をたどる追肥と緑の濃さのむら、飛ばせる段階 | まいたあと時間を進めると条に沿って芽が出て、追肥した畑は緑が濃くなる |
| W6 一年の暦 | 暦と生育、季節の色、日付で変わる太陽の通り道(北緯 43° 前後)、作業の時期、季節を見る早送り | 一年をタイムラプスで通して眺められる |
| W7 仕上げ | 音、保存、防除、ベールの回収など | 優先度を見て取捨選択する |

## 優先順位

1. W1 の麦畑の見え方。ここが弱ければ以降の方針を見直す。
2. W2 の収穫。刈り跡と麦わらの列がこのアプリのいちばんの見どころ。
3. 一年の作業を揃える(W3〜W5)。
4. 暦と季節の流れ(W6)。
