# goals — プロジェクトの目的と完成形

作成日時: 2026-11-11 04:54
更新日時: 2026-11-15 21:13

構想の詳細は [docs/reference/wheat-concept.md](../reference/wheat-concept.md) を参照。2026-11-15 に、芝刈りシミュレーター(lawn-mower)から小麦畑の一年を描くアプリ(wheatfield)へ方向を変えた。芝刈りのころの構想は [docs/reference/concept.md](../reference/concept.md) に残してある。

## 目的

なだらかな丘陵に広がる小麦畑で、耕す・整える・種をまく・育つ・刈り取る・麦わらをロールにまとめる、という一年の流れを、デスクトップ上で眺めて楽しめるアプリを作る。農作業の機械が畑に残す跡と、季節ごとに移り変わる畑の色を、ミニチュア風の実写寄りの絵で見せる。

## 完成形

- Electron アプリとして起動し、WebGL で 3D 描画する。
- グラフィックは実写寄り。少しデフォルメの入った、いくらかミニチュアっぽいリアルにする。絵の参考はユニクロカレンダー(見下ろしの構図、チルトシフト風の浅いピント、タイムラプス)。
- モデルと地形は実寸(1 単位 = 1 m)で作る。ミニチュア感はカメラ側の設定(ミニチュア倍率、ティルト)で出す。
- カメラは物理カメラとして扱う。焦点距離、絞り、自動露出、被写界深度を設定できる。
- 農道で区切られた複数の畑がある、数百 m 四方の丘陵の田園。
- 一年の暦があり、タイムラプスで季節が進む。秋に耕して種をまき、冬は緑の芽、春に穂が出て、初夏に黄金色に熟す。刈り取りのあとは刈り株と麦わらの列が残り、ロールベールが畑に並ぶ。
- 作業は次の順に行う。それぞれの作業が畑に固有の跡を残す。
  1. 耕起(プラウで土を反転する)
  2. 整地(ハローで砕いてならす)
  3. 播種(ドリルで筋状にまく)と鎮圧
  4. 生育(時間の経過で育つ。場所ごとのむらがある)
  5. 収穫(コンバインで刈り取る。刈り株と麦わらの列が残る)
  6. 麦わらの梱包(ロールベーラーで列を拾い、ロールベールを置いていく)
- 一年は作業の段階で進む。全部の畑でその段階の作業が終わったら次の段階へ進み、段階ごとに使う機械が入れ替わる。段階の中では、どの畑から作業するかを選べる。
- 手動モード: キーボードやゲームパッドで機械を運転できる。
- 自動モード: 選んだ畑(または、まだ作業していない畑を順に)を、作業に応じた経路で機械が自走し、それを好きな視点で眺められる。
- 機械(トラクター、作業機、コンバイン、ロールベーラー)とロールベールなどの 3D モデルは Blender で作る。モデルはスクリプトで生成し、寸法は機種の定義ファイルと共有する。

## 重視する価値

1. 畑の跡と色の美しさ。耕した筋、まいた条、タイヤの跡、刈り跡、麦わらの列、黄金色の穂波が、実写寄りの光の中できれいに見えること。
2. 季節の移り変わり。一年を早送りで眺めたとき、畑の色と様子が気持ちよく変わっていくこと。
3. 眺めて気持ちよいこと。自動走行と視点切り替え、早送り。カメラを操作して写真のように撮れること。
4. アルゴリズムが目で見て分かること。勾配による区分けと、作業ごとの経路計画。

## 当面やらないこと

- 本格的な車両物理(サスペンション、タイヤの滑りなど)。
- マルチプレイ、オンライン機能。
- 経営要素(お金、売買、収穫量の管理、病害虫など)。育つのを眺める「育成」は入れるが、管理や最適化のゲームにはしない。
- 芝生と芝刈り機(小麦畑に置き換える)。
